- `capitales.xlsx`: base entregada por el equipo, 47 capitales y coordenadas.
- `rutas_2020.csv`: DEMO sintética generada localmente. Sustituir por datos históricos verificados.

La etiqueta `DEMO` es intencional: evita confundir la prueba de software con evidencia empírica del informe.
